# Governance

py-atmos-serial is maintained by MarPi82 (`@marpi82`).

- **Code review**: pull requests to `main` require the code owner. Repository Admin may bypass, for a solo maintainer cutting a release.
- **Releases**: CalVer tags. `main` may cut stable or pre-release tags. `release/*` may cut pre-releases only. The Release workflow enforces this.
- **Security**: report privately. See [SECURITY.md](SECURITY.md).
- **Conduct**: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Decisions about the RS485 codec wait for captured traffic. A review that invents a frame layout should be rejected.
